## Quy ước đọc

- **Tasks** sử dụng checkbox: `[ ]` chưa bắt đầu, `[/]` đang làm, `[x]` hoàn thành.
- **Definition of Done (DoD)** là điều kiện bắt buộc để được coi là hoàn thành Phase.
- **Design Questions** là các câu hỏi bạn (EurusDevSec) phải tự nghiên cứu và trả lời trước khi bắt tay vào code.
